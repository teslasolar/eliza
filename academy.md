# ACG Guild Platform

The AI Craftspeople Guild's complete platform — vetting, standards, blockchain, scanning, and learning.

## What's Here

This is the root of the ACG Guild Platform, containing:

- **ELIZA** — Reverse Turing Test vetting interviewer (100% local via WebGPU)
- **KONOMI** — Self-Defining Industrial Standards System (18 packages)
- **Guild Chain** — ACG-KCC blockchain for ethical refusals and vetting records
- **Sandbox** — MCP tool environment with voice activation
- **Scanner** — Standards compliance linter
- **Academy** — Auto-discovered learning platform (you're reading this from it)

## The ACG Manifesto — Six Principles

1. **Embracing Innovation** — Explore AI, recognize potential, but verify independently
2. **Demanding Quality** — Rigorous verification, testing, validation before production
3. **Ensuring Safety & Security** — Proper harnesses for quality, safety, security, legal liability
4. **Protecting Humans** — Psychological safety for humans exposed to AI
5. **Respecting User Agency & Informed Consent** — AI use not hidden, transparency not optional
6. **Right and Duty to Refuse** — Refuse unsafe, deceptive, unverifiable AI systems

Created by Alex Bunardzic with Woody Zuill, Jona Heidsick, Matt Burch, Alex Thurow, Tsvetan Tsvetanov.

## Quick Start

Open `index.html` in a browser to see the platform hub. Everything runs locally — no servers, no API keys, no data transmitted.

## Architecture

Every directory is self-describing: each contains an `academy.md` that the Academy auto-discovers and teaches from. Drop an `academy.md` into any new directory and it becomes a learning module automatically.
