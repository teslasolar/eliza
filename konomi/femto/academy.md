# FemtoLLM — Tiny ML

Tiny language model for industrial classification — on-device, no cloud, minimal resources.

## Key Classes

- **FemtoLLM** — Tiny language model for classification tasks

## Core Concepts

- **Industrial Classification**: Categorize alarms, tag names, equipment types, fault descriptions
- **On-Device**: Runs entirely on the edge device — no network, no latency, no privacy concerns
- **Tiny**: Designed for microcontrollers and industrial PCs, not data center GPUs
- **Integration**: Works with eVGPU for compute, tag system for input, scanner for validation
