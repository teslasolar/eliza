# ISA-95 Enterprise/Control Integration

The 5-level Purdue Reference Model connecting business systems to the factory floor.

## Key Classes

- **Equipment** — Equipment model across all ISA-95 levels
- **Production** — Production scheduling and execution
- **Material** — Material tracking and definitions
- **Personnel** — Personnel qualifications and assignments

## The 5 Levels

- **L0** — Physical Process (sensors, actuators, the actual stuff)
- **L1** — Sensing & Direct Control (PLCs, DCS, RTUs)
- **L2** — Monitoring & Supervisory (SCADA, HMI, Batch control)
- **L3** — Manufacturing Operations (MES, LIMS, WMS)
- **L4** — Business Planning (ERP, BI, SCM)

ISA-95 defines the interfaces between these levels so enterprise and control systems can talk.
